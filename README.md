Campus AR Navigation
Overview

Campus AR Navigation is a web-based Augmented Reality (AR) navigation platform designed to help students, visitors, and hackathon participants easily locate important places on campus. The application provides real-time directions, event schedules, and location information through an interactive and user-friendly interface.

Features
🧭 AR-based campus navigation
📍 Locate labs, classrooms, auditoriums, and other key locations
📅 View hackathon and event schedules
🗺️ Interactive campus map
📱 Mobile-friendly design
⚡ Fast and responsive user experience
Technology Stack
HTML
CSS
JavaScript
AR.js / WebAR
Vercel (Deployment)
Use Case

This platform is especially useful during hackathons, college events, and campus visits, helping users quickly find destinations without confusion.
